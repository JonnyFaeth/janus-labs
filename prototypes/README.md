# Prototype plan

No executable prototype is included yet.

## Proposed walkthrough

Use a clearly fictional experiment to connect five views: research question, source notes, experiment brief, mock result summary, and interpretation notes. The walkthrough is an interaction demonstration, not a scientific simulation.

## Acceptance criteria

- Every example is labeled fictional.
- Observations, hypotheses, and generated suggestions are distinguishable.
- An interpretation links back to supporting records.
- Missing support and conflicting evidence remain visible.
- Human review is explicit before a draft plan is marked reviewed.
- Future code includes reproducible run instructions and limitations.

Do not include unpublished experimental protocols, real results, or equipment credentials.
