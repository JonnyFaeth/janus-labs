# Janus Labs roadmap

Proposed and unscheduled. No milestone below is represented as implemented.

## 1. Bound the research workflow

- [ ] Choose one researcher role and one planning or evidence-tracking problem.
- [ ] Create a fictional question, assumptions, and source notes.
- [ ] Identify decisions that require researcher review.

Done when: a single workflow has explicit inputs, outputs, non-goals, and success criteria.

## 2. Design provenance and review

- [ ] Sketch source notes, an experiment brief, and a result summary.
- [ ] Visually separate observations, hypotheses, and generated suggestions.
- [ ] Include missing evidence, contradictions, and uncertain interpretations.

Done when: a reader can trace a sample interpretation to its supporting fictional records.

## 3. Demonstrate the workflow

- [ ] Build a local walkthrough using synthetic material only.
- [ ] Connect a research question to a reviewed plan and mock result summary.
- [ ] Document supported actions and known limitations.

Done when: another person can reproduce the walkthrough without laboratory access or private data.

## 4. Evaluate and choose the next scope

- [ ] Ask researchers to assess usefulness and provenance clarity.
- [ ] Record unsupported suggestions and evidence-tracing failures.
- [ ] Review data permissions and confidentiality before considering real research.

Done when: evaluation findings justify a bounded next step. Hardware control remains outside this roadmap's initial scope.
